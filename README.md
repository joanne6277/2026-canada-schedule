# 行程與打包清單網頁

手機優先設計，可直接部署到網站。分成「行程」和「打包清單」兩個分頁：行程依城市整理交通、住宿、活動、餐飲、提醒；打包清單可以勾選，勾到哪裡會自動記住。

## 檔案說明

| 檔案 | 用途 | 需要動嗎 |
|---|---|---|
| **content.js** | **所有文字內容（行程與打包清單）** | ✅ 要改內容改這個 |
| styles.css | 顏色、字體大小、版面、列印樣式 | 想調外觀才動 |
| app.js | 產生畫面、切換分頁、記住勾選狀態 | 通常不用動 |
| index.html | 網頁骨架、社群預覽資訊 | 只有改版本號時動 |
| build.py | 合併成單檔（備用） | 只是執行 |

## 部署方式

把 `index.html`、`styles.css`、`content.js`、`app.js` 四個檔案上傳到靜態網站空間即可
（GitHub Pages、Netlify、Vercel、Cloudflare Pages 都行，免費方案就夠用）。

不需要資料庫或後端，也不需要 build。

### 更新內容的流程

1. 改 `content.js` 的文字
2. 順手更新 `content.js` 最上面的 `updated` 日期，家人就知道有新版
3. 把 `index.html` 裡的三個 `?v=2` 改成 `?v=3`（下次改再變 `v=4`）
4. 重新上傳 `content.js` 和 `index.html`

第 3 步是為了讓瀏覽器不要拿舊的快取版本。如果跳過這步，有些人可能會看到舊內容。

## 怎麼改內容

打開 `content.js`，找到要改的地方直接改文字。常見情境：

**新增一個要帶的東西** — 在對應清單的 `items` 裡加一行：

```js
{ text: "太陽眼鏡", note: "雪地反光很刺眼" },
```

`note` 是灰色小字說明，不需要就整段拿掉。加 `must: true` 會變紅字表示特別重要：

```js
{ text: "護照", note: "效期要到 2027 年 4 月以後", must: true },
```

**新增一整個分類** — 在 `checklists` 裡加一組：

```js
{
  id: "souvenir",        // 英文、不可重複
  nav: "伴手禮",          // 上方跳頁按鈕的字
  title: "伴手禮清單",
  hint: "回程前確認",      // 可省略
  items: [
    { text: "楓糖漿" }
  ]
},
```

**改行程** — 行程寫在 `content.js` 的 `itinerary` 裡，每個城市一組。

新增一個活動：在那一天的 `items` 裡加一行（`time`、`note`、`status` 都可以省略）：

```js
{ time: "下午", text: "卡皮拉諾吊橋", note: "建議早點去，人比較少", status: "tbd" },
```

新增一天：在該城市的 `days` 裡加一組：

```js
{ date: "10/23（五）", title: "市區觀光",
  items: [
    { time: "上午", text: "史丹利公園" }
  ] },
```

狀態標籤 `status` 有三種：`"booked"`（已訂，綠色）、`"confirmed"`（已確認，黃色）、`"tbd"`（待補，灰色）。從「待補」改成「已訂」只要改這個字。

城市的 `weather` 對應到「各地天氣」卡片的 `id`，改天氣只要改天氣卡片，行程分頁會跟著變。

**改交通** — `transport` 依日期分組，每組一個 `date` 標題和一個 `items` 陣列：

```js
transport: [
  { date: "10/15（四）", items: [
    { when: "12:30", title: "尼加拉瀑布 → 多倫多", note: "還車", status: "booked" },
    { when: "15:23 → 20:25", title: "多倫多 → 蒙特婁（火車）", note: "VIA Rail 66 次" }
  ] }
],
```

`when` 只要寫時間就好（不用重複寫日期，日期已經是那組的標題）；沒有明確時間的項目可以整段省略 `when`。`date` 也可以不是日期，例如「每晚」「市區內移動」這種不屬於特定一天的提醒，一樣可以自成一組。

每筆交通前面的圖示（✈️🚆🚗🚕🚇）是程式自動依 `title` 和 `note` 裡的關鍵字判斷的，不用自己加，關鍵字對照在 `app.js` 的 `TRANSPORT_ICON_RULES` 裡，例如寫到「航空」或「AC8024」這種兩個字母加數字的班機編號會自動配對飛機圖示，寫到「Hertz」「取車」「自駕」會配對開車圖示。

住宿寫在城市的 `stay` 裡，可以用的欄位：

```js
{ name: "Airbnb", address: "...", city: "QC",
  checkin: "...", checkout: "...",
  rooms: "四間雙人房＋客廳沙發床",      // 房型房間數，選填
  features: ["廚房", "洗烘衣機"],       // 設備，選填，沒有就整段拿掉
  parking: "路邊停車位",                // 停車方式，選填，不要寫金額（見下方「不要放上網頁的資訊」）
  note: "..." },
```

**注意事項**

- 每行結尾的逗號 `,` 不要刪
- 文字用雙引號 `"` 包起來
- `id` 改掉的話，那一段原本的勾選紀錄會重來

## 不要放上網頁的資訊

網站是公開的，GitHub 上的原始碼（包括註解）也看得到。以下資訊不要寫進任何檔案，請留在行程總表或自己手機裡：

- 訂位代號、PNR、確認碼、PIN、智慧鎖密碼、訂單號、租車確認號、發票號碼
- 任何金額與付款狀態
- 公寓的房號
- eTA 相關內容
- 境內段機票的行李額度與加購提醒

## 設計重點

**分頁**
- 頁首下方是「行程｜打包清單」分頁按鈕，捲動時會黏在最上面
- 網址加 `#itinerary` 直接開行程、`#packing` 直接開打包清單，可以這樣貼給家人
- 沒指定時會打開上次看的分頁；第一次打開時，10/8 出發前預設打包清單，出發後預設行程
- 行程的交通、住宿、餐飲、提醒預設收起來，活動預設展開；列印時全部自動展開

**手機**
- 字級手機 19px、平板以上自動放大到 20px（可在 `styles.css` 的 `--font-base` 調整）
- 整列都可以點，不用精準點到小方框；點擊區高度 58px 以上
- 跳頁按鈕手機兩欄、電腦四欄
- 錨點跳頁時會自動避開上方的進度條，不會被蓋住
- 有處理 iPhone 瀏海與底部 home 列的安全區域

**列印**（瀏覽器選「列印」或存成 PDF）
- 只印目前打開的那個分頁
- 自動隱藏分頁按鈕、進度條、跳頁按鈕、浮動按鈕、清除鍵
- 行程分頁每個城市從新的一頁開始
- 改成白底黑字、A4 直式，省墨水
- 清單印成空的方格，可以拿筆手寫打勾；螢幕上已勾選的會印出勾勾
- 卡片和清單項目不會被切到跨頁

## 其他

- 勾選狀態存在每個人自己的瀏覽器裡，各自獨立，不會互相影響
- 每個項目用「分類 + 項目名稱」當代號，之後增減項目不會弄亂已經勾好的
- 需要單一檔案時（例如直接用 LINE 傳），執行 `python3 build.py` 會在上一層產生 `行李打包清單.html`
